# Push_swap

A C sorting project that orders integers using two stacks and a limited instruction set.

## What it covers

- Parsing and validating integer arguments
- Detecting duplicates and invalid input
- Stack operations such as swap, push, rotate, and reverse rotate
- Sorting strategies for small and large inputs
- Operation counting and disorder analysis

The repository also includes a local `libft42` utility library and a Makefile for building the program.

## Build

```bash
make
./push_swap 2 1 3
```
